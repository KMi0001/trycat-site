# TRYCAT 사이트

소개 페이지 한 장짜리 정적 사이트예요. 서버가 필요 없어서 GitHub Pages로 그대로 올릴 수 있어요.

## 폴더 구성

```
index.html      메인 페이지
style.css       디자인
script.js       불 켜기/끄기, 고양이 눈, 문의 창
config.js       ★ 올리기 전에 채울 값 (이메일, 상호 등)
404.html        없는 주소로 들어왔을 때 보이는 페이지
favicon.svg     브라우저 탭 아이콘
assets/         이미지 (고양이 사진)
.nojekyll       GitHub가 파일을 그대로 쓰게 하는 표시 (지우지 마세요)
```

## 1. 올리기 전에 — config.js 채우기

`config.js`를 열어 값을 채워주세요. 비워두면 그 항목은 화면에서 자동으로 숨겨져요.

- `email` — 문의를 받을 이메일 주소. **비워두면 문의 영역이 통째로 숨겨져요.**
- `company`, `bizNo` — 하단에 보일 상호와 사업자등록번호. 원하는 것만 채우세요.
- `picmedicUrl` — PicMedic 웹 버전 주소. 아직 열려 있지 않으면 비워두세요.

> 저장소가 공개(public)이면 이 파일을 누구나 볼 수 있어요. 공개해도 되는 값만 넣어주세요.

## 2. GitHub에 올리기 (브라우저로)

1. GitHub에서 **New repository**를 눌러요. 이름은 자유고, 무료로 쓰려면 **Public**으로 만들어요.
2. 만든 저장소에서 **Add file → Upload files**를 눌러요.
3. 이 폴더 **안에 있는 파일과 `assets` 폴더를 통째로** 끌어다 놓아요.
   `index.html`이 저장소의 맨 위 칸에 있어야 해요. (폴더째로 올리면 한 칸 안으로 들어가서 안 보여요.)
4. `.nojekyll` 파일은 점으로 시작해서 탐색기에서 안 보일 수 있어요. 안 올라가도 사이트는 동작하지만, 올려두면 더 안전해요.
5. **Commit changes**를 눌러요.

## 3. Pages 켜기

1. 저장소의 **Settings → Pages**로 가요.
2. **Build and deployment**에서 Source를 **Deploy from a branch**로 두고, 브랜치는 **main**, 폴더는 **/ (root)**를 골라 **Save**해요.
3. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요.
   - 저장소 이름이 `계정이름.github.io`이면 → `https://계정이름.github.io/`
   - 그 외 이름이면 → `https://계정이름.github.io/저장소이름/`

이 사이트는 모든 경로가 상대 경로라서, 두 경우 모두 그대로 동작해요.

## 4. 도메인은 나중에

지금은 위 주소로 먼저 열어보세요. 도메인은 준비되면 이어서 연결하면 돼요.

- **Settings → Pages → Custom domain**에 도메인을 입력하면 저장소에 `CNAME` 파일이 자동으로 생겨요.
- 도메인을 산 곳의 DNS 설정에서 GitHub Pages 안내에 나온 값을 등록해요. (값은 연결할 때 GitHub 문서로 한 번 더 확인해주세요.)
- 연결이 끝나면 **Enforce HTTPS**를 켜요.
- 한 도메인은 저장소 하나에만 연결돼요. 이미 다른 사이트가 쓰고 있는 주소와 겹치지 않게 주의하세요.

## 5. 고칠 때

GitHub에서 파일을 열고 연필 아이콘을 눌러 고친 뒤 **Commit**하면 1~2분 뒤 반영돼요.

## 나중에 하면 좋은 것

- **PicMedic 화면 캡처**: `assets/picmedic.png`로 올리고, `index.html`에서 안내 주석이 붙은 img 줄을 살려요.
- **공유 미리보기 이미지(OG)**: 도메인이 정해진 뒤 전체 주소로 지정해야 해서, 도메인 연결 후에 넣는 걸 권해요.
- **개인정보 처리방침 링크**: 문의를 이메일로 받으니 짧게라도 두는 걸 권해요.

## 참고

- 문의 창은 서버로 보내지 않아요. 보내기를 누르면 **방문자의 메일 앱이 열리고 내용이 채워져요**. 그래서 사이트가 개인정보를 저장하지 않아요.
- 폰트(JetBrains Mono, Nanum Gothic Coding)는 Google Fonts에서 불러와요.
- 불 켜기/끄기 상태는 방문자 브라우저에 기억돼요.
